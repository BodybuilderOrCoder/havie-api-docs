# HAVIE API Docs

Tài liệu API của cửa hàng cầu lông HAVIE (OpenAPI 3.0).

- Xem online: https://bodybuilderorcoder.github.io/havie-api-docs/
- File spec: [openapi.json](openapi.json)

Repo này chỉ chứa tài liệu. File được tạo bằng lệnh `npm run docs:export` trong thư mục `backend` của dự án HAVIE.
